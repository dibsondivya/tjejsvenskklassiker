# Klassiker Training Log

Daily plan for En Svensk Klassiker Tjej, 23 Nov 2026 to 26 Sep 2027. Hosted on GitHub Pages.

## Files in this repo
- `index.html`: the app and the whole plan
- `plan-updates.json`: plan changes written by Claude after a review
- `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`: to make it installable as a phone app

Training log is NOT stored in this repo. It goes in a separate private repo so that notes stay private.
